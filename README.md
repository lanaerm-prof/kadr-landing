# KADR — сайт фотопечати

Статический лендинг с интерактивным калькулятором, формой заказа, страницей успеха и служебными страницами. Внешних зависимостей и сборки нет.

## Запуск локально

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Что умеет калькулятор

- Малые форматы А6/А5/А4 и большие форматы; у каждого кадра можно задать свой формат, бумагу и кадрирование.
- Количество отпечатков вводится вручную (1–999) или кнопками `−`/`+`.
- Автоматическая скидка за тираж: от 50 шт −10%, 200 шт −20%, 500 шт −30%. Она уже включена в цену за отпечаток.
- Вечерняя акция −5% с 20:00 до 23:00 применяется автоматически.
- Срочная печать доступна для форматов до А4; отсечка зависит от выбранного пункта выдачи (за час до закрытия).
- Результат можно выгрузить в XLSX и приложить к заявке.

## Форма и безопасность

Заявка отправляется через встроенную Яндекс Форму. В репозитории **нет API-ключей, токенов и секретов**. Идентификатор формы в `assets/js/yandex-form.js` является публичным: он отправляется браузеру как часть адреса iframe и не является секретом.

Предусмотрены:

- CSP с whitelist доменов, `referrer-policy`, `upgrade-insecure-requests`;
- проверка источника сообщений от iframe формы;
- honeypot-поле, кулдаун на повторную отправку и одноразовый токен формы;
- ограничение загрузки файлов: JPEG/PNG/WEBP до 20 МБ, длина имени файла ограничена;
- экранирование пользовательских строк в DOM и XLSX.

Для реального продакшена желательны серверная проверка данных, капча/Turnstile и заголовки безопасности на уровне хостинга (HSTS, X-Content-Type-Options, X-Frame-Options).
